## Компании (лицензии)

Продажа по компаниям: каждой компании — отдельный экземпляр сервера со своим
портом, паролем и данными (галерея, IFC-файлы изолированы автоматически).

| Действие | Команда |
|---|---|
| Создать компанию | `python create_company.py --name "ООО «А»" --code acme --valid-until 2027-09-05` |
| Запустить | `start_company.bat acme` |
| Остановить | `python stop_company.py acme` |
| Список | `python list_companies.py` |
| Сменить пароль | правка `companies/acme/.env` (SITE_PASSWORD), перезапуск не нужен |
| Продлить лицензию | правка `SITE_VALID_UNTIL` в `companies/acme/.env` |
| Отозвать немедленно | `python stop_company.py acme` + смена SITE_PASSWORD |

Пароли выдаются в `companies/<код>/CREDENTIALS.txt` (в git не входит).
Адрес компании: `http://<сервер>:<порт>` (порт из `companies.json`).
Все экземпляры используют общий патченный venv; после переустановки InvokeAI
повторить патчи один раз (см. «Проверка после изменений» в HANDOFF.md).

### Изоляция данных компании

Каждый экземпляр работает со своим корнем `companies/<код>/data`, поэтому
изолируются автоматически (без отдельных настроек):

- **Галерея сгенерированных картинок** — в корне компании; базовый
  экземпляр 9090 и другие компании её не видят.
- **IFC-модели** — в `companies/<код>/data/ifc/` (роутер кладёт файлы в
  `<INVOKEAI_ROOT>/ifc`); каталог создаётся сам при первой загрузке, новая
  компания стартует с пустым списком. Перенести готовые модели (например,
  демо-набор из `data/ifc/` базового экземпляра) — просто скопировать файлы
  в папку компании, перезапуск не нужен. Лимит 500 МБ на файл действует в
  каждой компании независимо.
- **Доступ** — все эндпоинты (включая `/api/v1/ifc/*` и картинки) закрыты
  мидлварью входа: без пароля компании файлы недоступны и по прямому URL.

### Срок лицензии и отзыв

- `SITE_VALID_UNTIL=ГГГГ-ММ-ДД` в `.env` компании: после этой даты любой
  запрос (включая вебсокеты и попытку входа с верным паролем) закрывается
  страницей «Лицензия истекла» с контактом devbim. Дата входит в токен
  куки — её смена мгновенно инвалидирует выданные куки.
- `SITE_PASSWORD`/`SITE_VALID_UNTIL` перечитываются из `.env` на каждом
  запросе: смена пароля, продление и «мягкий» отзыв работают **без
  перезапуска сервера**. Немедленный отзыв — `stop_company.py` + смена
  пароля.
- Лог экземпляра: `companies/<код>/server.log` (пишет start_company.bat).

## ImageRouter

Интеграция облачных моделей через [ImageRouter](https://docs.imagerouter.io/)
(OpenAI-совместимый шлюз: FLUX, GPT-Image, Nano Banana, Qwen-Image и др.).
Скриншоты: `docs/imagerouter-tab.png`, `docs/imagerouter-canvas.png`.

### Секреты: `.env` (ключ и админский пароль)

Секреты живут в `.env` в корне проекта и подтягиваются сервером при каждом
запуске (в браузер не отдаются; в git не входит):

| Переменная | Назначение |
|---|---|
| `IMAGEROUTER_API_KEY` | ключ ImageRouter; имеет приоритет над ключом, введённым через UI (`data/imagerouter.json`). Смена: поправить строку и перезапустить сервер |
| `ADMIN_PASSWORD` | админский пароль для входа в «Менеджер моделей» (см. следующий раздел) |

Если `.env` нет, `setup_imagerouter.py` создаёт шаблон (ключ переносится из
`data/imagerouter.json`, пароль — `change-me`). Проверка, что ключ подтянулся:
`GET /api/v1/imagerouter/status` → `"key_source":"env"`.

### Админский пароль: «Менеджер моделей» за шестерёнкой

«Менеджер моделей» (управление ключом, каталог, генерация) по умолчанию
закрыт и перенесён в настройки (19.08.2026, вечер):

- вкладка «Модели» убрана из левой вертикальной рейки;
- вход — через кнопку «Меню» (внизу рейки): в группе «Настройки» появились
  пункт **«Менеджер моделей»** и штатная шестерёнка «Настройки»;
- клик по шестерёнке «Настройки» или по пункту «Менеджер моделей» открывает
  **модальное окно ввода пароля** (скриншот: `docs/admin-password-modal.png`);
  пароль сверяется на сервере с `ADMIN_PASSWORD` из `.env`;
- после верного пароля открываются сами настройки / «Менеджер моделей»;
  разблокировка действует до перезагрузки страницы (F5 — снова пароль);
- обходные пути тоже закрыты: кнопка «Manage Models» в выпадающем списке
  моделей, горячие клавиши и прочие переходы на вкладку моделей перехватываются
  тем же окном пароля; восстановление вкладки «Модели» после перезагрузки
  возвращает на «Generate».

Если `ADMIN_PASSWORD` в `.env` пуст/отсутствует — защита отключена,
пароль не запрашивается (`GET /api/v1/imagerouter/admin-auth` → `protected`).

### Где модели ImageRouter в интерфейсе

- **Левая панель — только параметры API (19.08, вечер)**. Поскольку система
  работает только через API ImageRouter, из левой панели Generate и Canvas
  скрыты параметры, настраивающие исключительно локальные модели: аккордеоны
  «Refiner» и «Advanced» (VAE, VAE Precision, CFG Rescale, Seamless X/Y),
  «Compositing» (Coherence/Infill) на канвасе, блок «Concepts» (LoRA) и
  сворачиваемые «Advanced Options» с Scheduler/Steps/CFG Scale. Осталось
  только то, что реально уходит в API: промпт (+Reference Image), модель,
  размер (Aspect/Width/Height → `size`), seed. «Advanced Options» внутри
  аккордеона «Image» на канвасе оставлен — это масштабирование кадра
  (Scale Before Processing), оно определяет кроп/размер исходника для правки.
  Патч применяется функцией `patch_left_panel()` в `setup_imagerouter.py`.
- **Меню добавления слоёв канваса — без Control Layer (05.09)**. Пункт
  «Слой управления» (ControlNet) убран из меню «+» панели Control Layers:
  ControlNet-модели работают только с локальной генерацией, которой нет.
  Остаются Inpaint Mask, Regional Guidance, Regional Reference и растровый
  слой — всё, что уходит в облачный edits-запрос. Существующие control-слои
  в сохранённых канвасах продолжают отображаться (удаляются вручную).
  Функция `patch_canvas_control_layer()` в `setup_imagerouter.py`.
  Вкладка Upscaling не тронута — планируется модернизация под облако.
- **Левая вертикальная рейка вкладок (19.08, вечер)** — скрыты: вкладка
  «Очередь» (статус генерации и так виден у кнопки Generate), колокольчик
  уведомлений (в его поповере показывается «Что нового в DevBIM» —
  обновления локальной сборки не актуальны; всплывающие тосты об ошибках
  остаются) и кнопка Support Videos. Функция `patch_left_rail()` в
  `setup_imagerouter.py`.
- **Canvas / Generate (основной экран генерации)** — модели ImageRouter
  появляются прямо в выборе модели рядом с локальными; генерация с ними
  выполняется через API ImageRouter, результат сохраняется в галерею как
  обычное изображение (штатные события `invocation_complete` и т.д.).
  Промпт и размер берутся из графа; «число итераций» = количество картинок
  (не более 10 за раз). Параметры steps/cfg/scheduler облачными моделями
  игнорируются — у API есть только size/quality. Во время генерации видна
  строка прогресса («модель · i/N · секунды») и счётчик очереди — облачный
  запрос отображается в UI как обычная генерация.
- **Редактирование (inpaint/outpaint/img2img)** — если на канвасе есть
  исходное изображение, запрос уходит в `/v1/openai/images/edits`:
  передаются промпт и исходное изображение. Маска слоя Inpaint Mask
  учитывается так: зона правки подсвечивается прямо в картинке (шлюз
  ImageRouter не принимает параметр маски ни у одной модели), а результат
  вклеивается **только внутрь выделенной зоны** — всё остальное изображение
  остаётся пиксельно исходным. Требуется модель с пометкой «редактирование»
  в описании (например `google/nano-banana-2`, `qwen/qwen-image-edit`,
  `openai/gpt-image-2`, `black-forest-labs/flux-kontext-*`);
  для остальных вернётся понятная ошибка. Промпт описывает, что сделать
  с выделенной зоной («удали балкон», «поставь кондиционер»).
- **Референсные изображения (Reference Image)** — добавьте на канвас
  референс и выберите в его панели модель **ImageRouter (референс)**
  (без выбранной модели клиент игнорирует референс и показывает «!»).
  Референсные картинки передаются в API как дополнительные входные
  изображения (`image[]`) вместе с промптом; работает и вместе с правкой
  (подложка + маска + референсы), и без подложки. Требуется модель
  с пометкой «редактирование».
- **Model Manager — за админским паролем (19.08.2026, вечер)**: вкладка
  «Модели» убрана из левой рейки; вход через «Меню» → группа «Настройки» →
  пункт **«Менеджер моделей»** (или шестерёнка «Настройки») с вводом пароля
  из `.env` (`ADMIN_PASSWORD`). Внутри — вкладка **ImageRouter**: ввод/проверка
  ключа, каталог моделей (поиск, фильтр «только бесплатные», сортировка, цены)
  и форма генерации с просмотром результата. Вкладки установки локальных
  моделей (Launchpad, URL/путь, HuggingFace, скан папки, стартовые модели)
  скрыты.

Технически: модели помечаются ключами `imagerouter/<provider>/<model>` и
показываются как main-модели (base sdxl — только чтобы граф собрался;
локально ничего не исполняется). Запрос `enqueue_batch` с такой моделью
перехватывает мидлварь `ImageRouterCanvasMiddleware`: вызывает
`/v1/openai/images/generations`, сохраняет картинку через сервис галереи и
отправляет клиенту события как при обычной генерации. Удаление такой
«модели» из списка заблокировано (это каталог API, а не файлы).

Главная кнопка генерации переименована из «DevBIM» в понятную
**«Generate»** (левая панель, рядом со счётчиком итераций; также
Ctrl+Enter и «Add to Queue» на панели канваса). Подсказки интерфейса,
упоминавшие нажатие кнопки, обновлены.

API бэкенда (Swagger: `/docs`): `GET /api/v1/imagerouter/status`,
`PUT|DELETE /api/v1/imagerouter/key`, `GET /api/v1/imagerouter/credits`,
`GET /api/v1/imagerouter/models`, `POST /api/v1/imagerouter/generate`,
`GET|POST /api/v1/imagerouter/admin-auth` (статус защиты / проверка пароля).

роутера + мидлварь), `index.html` (подключение `/devbim-admin.js`) и собранный
JS (вкладки, меню, охрана переключения). Бэкапы — `*.imagerouter-bak` рядом
с патчеными файлами. После переустановки пакета `invokeai` запустить повторно
(как и `rebrand_devbim.py`). Откат: восстановить `*.imagerouter-bak`, удалить
`routers/imagerouter.py`, `dist/imagerouter.html` и `dist/devbim-admin.js`.

### Тумблер «Mask / Layer» на холсте

Над нижней панелью холста плавает пилюля с двумя кнопками:
- **Mask** — кисть рисует полосатой маской (зона для правки/inpaint);
- **Layer** — кисть рисует обычным цветом по картинке.

Подписи — базовый английский; русская адаптация под язык интерфейса —
отдельная задача.

Подсветка показывает, чем рисует кисть прямо сейчас; клик переключает слой
(если слоя нет — создаётся). Полезно после кнопки «На холст» из IFC-вьювера:
она сама выделяет слой маски, и без индикации это неочевидно. Конкретный
слой по-прежнему можно выбрать в панели слоёв справа.

Реализация: `imagerouter/devbim_mask_toggle.js` (деплой
`setup_imagerouter.py` → `dist/devbim-mask-toggle.js`) + однострочный мост в
App-бандле (`patch_canvas_bridge`). Правка вида — правка JS-файла с
повторным запуском `setup_imagerouter.py`. Откат: восстановить
`*.imagerouter-bak` и `index.html.masktoggle-bak`, удалить
`dist/devbim-mask-toggle.js`.

### Диагностика

- Тост «Не удалось поставить пакет в очередь» показывает текст ошибки
  ImageRouter (нет ключа, модель без правки, сбой облака). Если вместо
  текста «Неизвестная ошибка» — смотрите `ir_server.log` и дамп графа
  `data/_ir_last_graph.json`.
- При каждом перехвате генерации граф сохраняется в
  `data/_ir_last_graph.json` — по нему видно, что реально ушло с канваса
  (модель, промпт, картинка, маска).
- «API-ключ не задан» — задать `IMAGEROUTER_API_KEY` в `.env` и перезапустить
  сервер (или ввести ключ на вкладке ImageRouter — сохранится в
  `data/imagerouter.json`; значение из `.env` имеет приоритет).
- «Неверный пароль» в окне администратора — пароль задаётся `ADMIN_PASSWORD`
  в `.env`; после правки перезапустить сервер. Забыли пароль — откройте `.env`.
- Окно пароля не появляется — защита отключена (`ADMIN_PASSWORD` пуст или
  нет `.env`): `GET /api/v1/imagerouter/admin-auth` → `{"protected":false}`.
- «Модель не поддерживает редактирование» — выбрана text-to-image модель,
  для правки фото нужна модель с пометкой «редактирование».
- «Не удалось загрузить исходное изображение» — канвас ссылается на
  удалённую картинку (например, после чистки галереи); заново положите
  изображение на канвас.
- Порт 9090 занят другим процессом — проверьте, что не запущено два
  сервера (`netstat -ano | findstr :9090`), лишний завершите.

## IFC-вьювер (BIM)

Отдельная вкладка **«IFC»** в левой рейке (после «Рабочие процессы») —
3D-просмотрщик BIM-моделей в формате IFC. Геометрия разбирается прямо в
браузере (web-ifc WASM + @thatopen/components, всё локально, без CDN);
сервер только хранит файлы. Скриншот: `docs/ifcviewer-tab.png`.

Возможности:

- открытие IFC с диска («Открыть файл…») или из списка моделей на сервере
  (загружаются через API, хранятся в `data/ifc/`);
- орбитальная камера: ЛКМ — вращение, колесо — зум, ПКМ — панорама;
- дерево здания: проект → площадка → здание → этажи → элементы;
- клик по элементу (в 3D или дереве) — подсветка + свойства: атрибуты
  и наборы свойств (psets) с количеством;
- «Скрыть» / «Изолировать» / «Показать всё» для выделенных элементов
  (в дереве скрытые показываются тусклыми);
- секущие плоскости: «Сечение» добавляет горизонтальную плоскость,
  которую можно тянуть мышью; «✕ сечения» убирает все;
- водяной знак движка @thatopen отключён (`showLogo = false`), вместо
  него в левом нижнем углу вьюпорта — знак «DevBIM — Design»
  (не перехватывает клики, виден и в embed-режиме на «Холсте»).

### Панель «IFC Viewer» на вкладке «Холст» (снимок модели → генерация)

Вкладка **«Холст»**, главная область: рядом с «Image Viewer» есть панель
**«IFC Viewer»** — тот же вьювер без боковых панелей (шапки, дерева,
свойств). Внизу плавающая панель: селектор моделей с сервера и кнопки
**«📸 На холст»** и **«✨ Сгенерировать»**. Скриншоты:
`docs/ifcviewer-canvas-panel.png`, `docs/ifcviewer-canvas-underlay.png`.

Как это работает:

- «📸 На холст» делает снимок текущего 3D-вида (белый фон, стороны кратны
  64 — требование ImageRouter), загружает его в галерею и кладёт на холст
  **базовым растровым слоем-подложкой** (холст очищается, рамка подгоняется
  под снимок); приложение переключается на рабочую область холста;
- «✨ Сгенерировать» делает то же и сразу запускает генерацию холста —
  снимок уходит в модель как img2img (прозрачные области холста при
  желании дорисовываются; промпт и модель — обычные настройки слева);
- для правки снимка выбирайте **модель правки**: `google/nano-banana:free`,
  `openai/gpt-image-2:free`, `qwen/qwen-image`,
  `black-forest-labs/flux-kontext-dev`. Обычные генеративные модели
  (например, `illustrious-xl`) вход-картинку не редактируют — посредник
  обнаружит «эхо» (модель вернула вход без изменений) и выдаст понятную
  ошибку вместо фейкового результата. У `:free`-моделей лимит
  3 запроса в сутки;
- **маску рисовать не обязательно**: без маски правится вся картинка —
  прозрачные поля вокруг снимка заливаются белым, и модель дорисовывает
  окружение по промпту («добавь окружение»). Если нужна локальная правка —
  нарисуйте «Маску перерисовки» (слой маски + кисть), тогда изменится
  только выделенная зона. Кнопка Generate блокируется, если на холсте
  есть слой «Региональная точность» без промпта — удалите его или
  впишите промпт;
- модель в панель подгружается автоматически: берётся последняя модель,
  открытая на вкладке «IFC» (синхронизация через localStorage, включая
  живую подмену при переключении); локальные файлы с диска не
  синхронизируются — используйте селектор в панели;
- панель неактивна — вьюпорт выгружается (модель при возврате
  перезагрузится автоматически, положение камеры сбросится).

Технически: iframe `/ifcviewer.html?embed=1`; снимок — форс-рендер +
`toDataURL` (WebGL-буфер живёт только в кадре рендера); мост
`window.__devbimIfc.toCanvas(imageDTO, generate)` в App-бандле (патч
`setup_ifcviewer.py`) переиспользует механизм «Send to Canvas» и запуск
генерации холста. Детали и грабли — HANDOFF.md, п. 13.

API бэкенда (Swagger: `/docs`): `GET /api/v1/ifc/list`,
`POST /api/v1/ifc/upload` (multipart `file`, до 500 МБ, только
`.ifc`/`.ifczip`/`.ifcxml`), `GET|DELETE /api/v1/ifc/file/{name}`.
Имена проверяются — пути (`../`) не проходят.

### Технологии и версии (фиксированы, см. `ifc/build_assets.sh`)

@thatopen/components 3.4.8 + @thatopen/fragments 3.4.7 + three 0.182.0 +
web-ifc 0.0.77 + camera-controls 3.1.2. Ассеты в `ifc/assets/`:
`thatopen.mjs` (esbuild-бандл, ~6 МБ), `worker.mjs` (воркер разбора —
кладём локально: по умолчанию библиотека тянет его с unpkg.com),
`web-ifc.wasm`. Обновление версий — правкой `ifc/build_assets.sh`
(нужен Node.js/npm, папка `ifc_assets/`).

  Большие проекты (>100 МБ) разбираются в браузере десятки секунд —
  следите за статусом внизу страницы.
- Вкладка «IFC» пропала после переустановки пакета — повторите
  `setup_ifcviewer.py` (см. выше).
- 404 на `/ifc/thatopen.mjs` — ассеты не развернуты: запустите
  `setup_ifcviewer.py`.
- Разработка страницы: отладка из консоли браузера — объект
  `window.__ifc` (модель, выбор, raycast, клипер) прямо в iframe.

Разработка ведётся в ветке `feature/ifc-viewer` (эксперимент).

## PDF-вьювер

Отдельная вкладка **«PDF»** в левой рейке (после «IFC») — просмотр
PDF-документов и нарезка фрагментов в картинки для дальнейшей работы
(подложка на холсте / ассеты галереи). Рендеринг — PDF.js 5.4.149, ассеты
лежат локально (`dist/pdf/`, без CDN); сервер только хранит файлы.
Скриншоты: `docs/pdfviewer-selection.png` (рамка фрагмента),
`docs/pdfviewer-to-canvas.png` (фрагмент на холсте).

Возможности:

- открытие PDF с диска («Открыть файл…») или из списка документов на
  сервере (select в шапке); кнопка «⬆ На сервер» сохраняет открытый с
  диска документ в хранилище (API `/api/v1/pdf/list|upload|file/{name}`,
  хранение `data/pdf/` — у каждой компании своя папка, лимит 500 МБ);
- поиск страницы: миниатюры в левой панели (ленивый рендер), оглавление
  документа (если есть — вкладка «Оглавление»), поле номера страницы и
  стрелки, клавиши ←/→/PageUp/PageDown;
- зум (кнопки −/+, Ctrl+колесо, «100%»), «↔ Ширина», «⛶ Вписать»,
  поворот «↻» на 90°;
- **рамка фрагмента**: ЛКМ-перетаскивание по странице (вне рамки область
  затемняется), новая рамка заменяет прежнюю, ESC или клик — сброс;
- **«🖼 На холст»** — фрагмент загружается в галерею и кладётся на холст
  как при кнопке «Редактировать»: растровая подложка + выделенный слой
  «Маска перерисовки» + кисть (рисуйте штриховку по маске и Generate);
- **«💾 В ассеты»** — фрагмент сохраняется в галерею, вкладка «Assets»
  (категория `user`); на холст не кладётся;
- качество: фрагмент рендерится заново в высоком разрешении (целевая
  длинная сторона 2048 px, лимит полной страницы 16 Мп, белый фон);
- автозагрузка: последний серверный документ и страница восстанавливаются
  при открытии вкладки (переключение вкладок размонтирует iframe);
- защищённые паролем PDF — запрос пароля (3 попытки).
