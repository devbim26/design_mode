================================================================
 DevBIM Image Studio - ФАЙЛЫ ЗАПУСКА (папка launch\)
================================================================

ЧТО ЗАПУСКАТЬ В 90% СЛУЧАЕВ
----------------------------
  start-system-design.bat   <- ГЛАВНЫЙ. Поднимает сервер + туннель
                               design.dev-bim.com. Безопасно запускать
                               всегда: что уже работает - не трогает.

ОСТАЛЬНЫЕ ФАЙЛЫ (когда нужны)
------------------------------
  open_frontend.bat         Открыть программу в браузере (если сервер
                            выключен - сначала включит).
  status-design.bat         Проверить, всё ли работает (первый помощник
                            при "что-то не открывается").
  stop-system-design.bat    Остановить всё (сервер + туннель).
  start_server.bat          Принудительно ПЕРЕЗАПУСТИТЬ сервер
                            (после правок кода / патчей venv).
  run-tunnel-design.bat     Только окно туннеля (сервер уже работает).
  start_devbim.bat          Сервер в окне консоли - отладка "глазами",
                            логи видно live. Редко нужно.

СЛУЖЕБНЫЕ (не запускать руками)
--------------------------------
  _restart_server.ps1       Перезапуск сервера отсоединённо (WMI).
                            Используется агентами и start_server.bat.
  _ir_server_hidden.bat     Скрытый старт сервера (вызывается из
                            _restart_server.ps1). Лог: ir_server.log
                            в корне проекта.

КОМПАНИИ (в корне проекта, НЕ здесь)
-------------------------------------
  create_company.py / start_company.bat / stop_company.py /
  list_companies.py - управление экземплярами компаний (порты 9100+).

МНОГОПОЛЬЗОВАТЕЛЬСКИЙ РЕЖИМ (users)
-----------------------------------
  Страница входа: почта + пароль (+ токен ImageRouter при первом входе).
  Вход владельца-админа: ПУСТАЯ почта + SITE_PASSWORD из .env,
  затем http://localhost:9090/admin - управление пользователями.
  Создать пользователя из консоли (в корне проекта):
    python user_manager.py add ivan@mail.ru
  Подробнее: docs\MULTIUSER.md

АДРЕСА
------
  Локально:          http://localhost:9090
  Публичный сайт:    https://design.dev-bim.com  (нужен туннель)
  Лог сервера:       ..\ir_server.log
