# Спека: Менеджер моделей — ImageRouter на весь экран, без левого списка

Дата: 19.09.2026. Запрос пользователя: «в менеджере моделей удали настройки
слева список, а настройки ImageRouter для различных типов генераций — сделай
по всему экрану, чтобы удобно было видеть всю информацию: параметры, деньги
и др., и настраивать — добавлять, удалять, доступность модели».

## Проблема

Вкладка «Модели» (Менеджер моделей, гейт по паролю) — это родной layout
InvokeAI: слева список моделей (ModelManager: поиск, фильтр, «Основные»,
кнопки удаления) на 50% ширины, справа ModelPane с единственной живой
вкладкой «ImageRouter» (iframe imagerouter.html). Левый список бесполезен
(модели не локальные, а Inject-фичи ImageRouter), съедает половину экрана,
а настройки ImageRouter сжаты в оставшуюся половину — цены/параметры не
разобрать. Сама страница imagerouter.html — одна узкая колонка секций,
листать приходится долго.

## Решение

1. **`setup_imagerouter.py`: новый патч `patch_models_tab_fullscreen()`**
   (идемпотентный, бэкап тот же `*.imagerouter-bak`). Компонент вкладки
   «models» — `()=>o.jsxs(E,{layerStyle:"body",w:"full",h:"full",gap:"2",p:2,
   children:[o.jsx(ModelManager,{}),o.jsx(ModelPane,{})]})` — заменяется на
   iframe `/imagerouter.html` на всю ширину и высоту вкладки (без паддингов).
   Regex не привязан к минифицированным именам ( `\w+` ), маркер «уже
   пропатчено» — `h:"full",p:0,children:[o.jsx("iframe",{src:"/imagerouter.html"`.
   Патч InstallModels (JS_NEW_COMPONENT) сохраняется: на свежем бандле цепочка
   идемпотентности не меняется, после fullscreen-патча компонент мёртв, но
   безвреден.

2. **`imagerouter/imagerouter.html`: полноэкранный layout.**
   - Шапка (2 строки): логотип, чип статуса ключа, чип баланса, ссылки;
     вторая строка — ввод/сохранение/удаление API-ключа (компактно).
   - Тело: 4 колонки с независимой прокруткой (`display:grid;
     grid-template-columns:repeat(4,1fr)`), каждая секция — своя колонка:
     1. **Каталог моделей** — поиск, «только бесплатные», сортировка,
        обновление; строки: провайдер/имя, бейджи параметров (edit, quality,
        размеры в tooltip), цена ~$/img или free. Клик — выбрать модель для
        тест-генерации.
     2. **Генерация и правка** — модели для пользователей: поиск, чекбоксы
        доступности (добавить/удалить), ↑↓ порядок (первая = по умолчанию),
        «Все/Снять» по фильтру, цена и бейджи (раньше цен здесь не было —
        админ просил видеть деньги), краткое описание.
     3. **Апскейлинг** — то же для вкладки Upscaling (только модели со
        входом-image).
     4. **3D-генерация + Генерация (тест)** — выбор VLM-аналитика; тестовый
        прогон выбранной модели каталога (промпт, размер, качество, формат).
   - Все id элементов сохранены (тесты: `id="threedsec"` в test_threed.py).
   - Цены показываются во всех списках (это админ-страница; решение 08.09
     «без цен» касалось пользовательских описаний моделей в инъекции).

## Проверка

- Парсинг бандла: `node -e "import('file:///...App-*.js')..."` — допустима
  только рантайм-ошибка, не SyntaxError.
- `venv\Scripts\python.exe tests\test_threed.py` (и соседние тесты секций).
- E2E Playwright: вкладка «Модели» — левого списка нет, настройки на всю
  ширину, 4 колонки, чекбокс+Сохранить работают. Скриншот
  `docs/model-manager-fullscreen.png`.
