# Спека: английский язык по умолчанию + переключатель EN/RU + полная русская локализация

Дата: 2026-10-08. Ветка: `user`.

## Контекст

Интерфейс InvokeAI многоязычен: переводы лежат в
`dist/locales/<lang>.json` (включая `ru.json`), выбранный язык хранится
в persisted-стейте redux (`IndexedDB «invoke» → «invoke-store» →
«@@invokeai-system» → language`; дефолт приложения — `"en"`, срез
`system` в бандле `index-*.js`: `languageChanged:(e,t)=>{e.language=t.payload}`,
тип экшена `system/languageChanged`). Выбор языка штатно спрятан в
Settings → Language, наружу не выведен.

Проблемы (запрос пользователя 08.10):

1. Баннер DevBIM (`devbim_banner.js`) до первого чтения настроек
   показывает русский слоган «Создавай реалистичные…» — а дефолт
   продукта английский. То же начальное `lang='ru'` у кнопок
   ✨/3D (`imagerouter/devbim_topright_buttons.js`). Кнопка «Выйти»
   в баннере — только по-русски.
2. Русская локализация неполная: в `ru.json` отсутствуют 585 ключей из
   2031 en (слои холста controlLayers, тосты, common, горячие клавиши,
   launchpad и др.) — при ru-интерфейсе существенные куски UI остаются
   английскими.
3. Тултипы вкладок левой рейки (`setup_navbar_labels.py`, карта DBLT) —
   только русские, от языка интерфейса не зависят.
4. Переключателя языка на виду нет — пользователь не знает, как
   включить русский.

## Решение

1. **Баннер — дефолт EN + переключатель.** `devbim_banner.js`:
   - начальный `lang='en'` (английский — дефолт продукта);
   - «Выйти» локализуется (ru «Выйти» / en «Log out»);
   - справа в баннере — сегментный переключатель `EN | RU`:
     * клик диспатчит `{type:'system/languageChanged', payload:'ru'|'en'}`
       в стор приложения. Стор доступен через глобал
       `window.__devbimPEStore` (его держит свежим патч App-бандла
       `DevbimPEWatch` из `setup_imagerouter.py`; фолбэк —
       `window.__devbimCanvasBridge.getManager().stateApi.store`);
     * App-компонент слушает селектор `system.language` и зовёт
       `i18n.changeLanguage` — весь интерфейс, включая переводы
       оверлеев (баннер/✨/3D), переводится сразу, без перезагрузки;
       redux-remember сам персистит выбор в IndexedDB;
     * если стор ещё не готов (баннер отрисован раньше React),
       язык пишется напрямую в IndexedDB `@@invokeai-system`
       (merge с существующим документом) — применится после F5;
     * активный язык подсвечивается; поллинг IDB (уже есть, 1 c)
       синхронизирует переключатель, если язык сменили в Settings.
2. **Кнопки ✨/3D Design** (`imagerouter/devbim_topright_buttons.js`):
   начальный `lang='en'` (та же причина — до чтения настроек показываем
   английский).
3. **Полная русская локализация.** Новый `setup_ru_locale.py` +
   словарь `locales_patch/ru_missing.json` (448 переводов; разделы
   `workflows.*` и `nodes.*` сознательно не переводим — вкладка
   Workflows скрыта из рейки, UI недостижим). Скрипт глубоким merge
   дополняет `dist/locales/ru.json` только ОТСУТСТВУЮЩИЕ ключи —
   идемпотентен, апстримные значения не трогает. Запускать после
   `rebrand_devbim.py` (он перезаписывает все локали; значения словаря
   уже брендированы «DevBIM»). Статика отдаётся с диска — достаточно
   F5. Особенности переводов:
   - плейсхолдеры `{{count}}`, `<LinkComponent>` и вложенные
     `$t(controlLayers.…)` сохраняются;
   - для плюрализуемых ключей i18next (`_one`/`_other` в en) в ru
     кладём полный набор русских форм `_one/_few/_many/_other`
     (Intl-правила русского плюрализма).
4. **Тултипы рейки — bilingual.** `setup_navbar_labels.py`: карта
   DBLT становится `tab: [подпись, тултип EN, тултип RU]`; тултип в
   рендере `Ad` выбирается селектором `T(_G)==='ru'` (`_G` — селектор
   `system.language` из того же App-бандла; читается в рендере — TDZ
   нет, как у DBLT). Скрипт умеет мигрировать уже-пропатченный бандл
   v1 (2-элементная карта) на v2, якорь свежей установки не меняется.
5. **Деплой/порядок**: `rebrand_devbim.py` → `setup_ru_locale.py` (новый,
   в любое место после rebrand) → `setup_imagerouter.py` (кнопки) →
   … → `setup_navbar_labels.py` (по-прежнему строго последним).

## Не делаем

- Перевод `workflows.*`/`nodes.*` (UI скрыт), локализацию админ-панели
  `devbim-admin.js` (RU по запросу пользователя, только админы) —
  кандидаты на потом.
- Другие языки кроме EN/RU в переключателе (полный список остаётся
  в Settings → Language).

## Проверка

- `venv\Scripts\python.exe tests\test_ui_language.py` — дефолты EN,
  комплектность ru.json, маркеры патчей, брендинг.
- `node --check` баннера/кнопок + node-import пропатченного App-бандла
  (только runtime-ошибка, не SyntaxError).
- Живая проверка в браузере: переключатель меняет язык интерфейса и
  слоган баннера сразу; после F5 выбор сохраняется.
