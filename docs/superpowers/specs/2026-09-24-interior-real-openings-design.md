# Спека: настоящие проёмы в интерьерном сборщике (interior)

24.09, ветка `interior`. Жалоба пользователя: «окна создались как
IFCBUILDINGELEMENTPROXY, проёмы под них не создались, окна выехали за
пределы помещения».

## Проблема (диагностика по `3D_interior_20260924-184114.ifc`)

1. Проёмы — прокси-коробки `IfcBuildingElementProxy` НАКЛАДЫВАЮТСЯ на
   сплошную стену: `IfcOpeningElement`/`IfcRelVoidsElement` нет, стена за
   стеклом цельная. Следствия: внешний BIM видит «наклейку»; снимок для
   ИИ-рендера показывает сплошную стену под стеклом (промту приходится
   это компенсировать гвардом из п.53).
2. Геометрия не клампится в стену-носителя: живой кейс 18:41 — окно
   торчит за торец стены на 0,21 м (висит за углом), дверь стоит на
   «огрызке» стены 0,2 м под 90° к нему (шире стены в 2,5 раза).
   Промахи источника: VLM x_px/wall_idx + validate_scene клампит только
   абсолютные размеры, не посадку на сегмент.

## Решение

`threed/threed_build.py::build_interior`:

- Каждое отверстие в стене (не на контуре) строится как:
  - `IfcOpeningElement` (box сквозь стену, толщина + 0,02 м — чистый
    булев, заподлицо глитчит) + `feature.add_feature` → IfcRelVoidsElement;
  - заполнение `IfcDoor`/`IfcWindow` (тонкий box ВНУТРИ проёма,
    глубина min(толщина−0,04; 0,08), без выступа за плоскости стены) +
    `feature.add_filling` → IfcRelFillsElement; стили Door/Window как
    раньше (окно — прозрачное IfcSurfaceStyleRendering), ObjectType
    CONCEPTUAL_DOOR/WINDOW сохранён.
- Кламп посадки проёма: стена-носитель ≥ 0,6 м (огрызки проёмов не
  держат — пропуск); ширина ≤ длина−0,1; центр так, чтобы проём целиком
  в сегменте с полями 0,05 м; высота ≤ wall_height − sill − 0,05;
  ширина/высота < 0,3 м — пропуск.
- Проёмы `wall_idx: "outline"` — без стены-носителя: остаются прокси
  (как раньше), контур не держит булева.
- rbox: контейнер/стиль опциональны (opening не входит в spatial
  структуру и не стилизуется).

Совместимость: палитра/стили стен и окон не меняются (п.54 живёт);
превью рисуется по сцене, не по IFC; `threed_verify._BUILT_CLASSES`
+= IfcDoor/IfcWindow (обзор сборки честно считает новые классы);
дерево вьювера покажет IFCWINDOW/IFCDOOR вместо прокси. web-ifc
(@thatopen) вычитает opening из стены сам — проверяется живым просмотром.
