# Спека: подписи под пиктограммами левой рейки + поясняющие тултипы

Дата: 2026-10-08. Ветка: `user`.

## Контекст

Левая вертикальная рейка (VerticalNavBar `fq` в App-бандле) — столбец
кнопок-вкладок `Ad` (displayName `TabButton`): IconButton 24px в тултипе
`$e` (placement:"end", label = короткое имя). Сейчас подписей под
иконками нет, назначение вкладок (IFC/PDF/Design Code) пользователю
неочевидно. Кнопка Workflows видна, хотя вкладка недоступна (локальная
сборка без движка workflows).

Запрос пользователя (08.10): под каждой эмблемой короткий текст —
Generate, Canvas, Upscaling, IFC, PDF, Design…; Workflows скрыть,
пока недоступна; при наведении — поясняющий текст («это
соответствующий вьювер» и т.п.).

## Решение

1. **Новый скрипт `setup_navbar_labels.py`** (запускается ПОСЛЕДНИМ,
   после `setup_style_presets.py`): правит App-бандл (тот же, где
   `displayName="TabContent"` / `displayName="VerticalNavBar"`).
   - **Переписывает определение `Ad`**: перед кнопкой объявляется карта
     `DBLT = {tab: [caption, tooltip]}`; кнопка оборачивается в колонку
     `E` (flexDir:"column") — сверху прежний IconButton без изменений,
     снизу текст `W` (fontSize 9px, color base.400 / invokeYellow.300 у
     активной вкладки, clickable через onClick на контейнере — клик по
     подписи тоже переключает вкладку). Тултип берёт из карты
     пояснение, для вкладок вне карты — прежний label.
   - **Удаляет кнопку Workflows** из рейки: вырезается фрагмент
     `a&&o.jsx(Ad,{tab:"workflows",…}),` (уникален). Контент вкладки в
     TabContent не трогается — кнопка вернётся перезапуском скриптов
     без navbar_labels.
   - Почему отдельный скрипт и почему последним: якорь вставки вкладки
     IFC в `setup_ifcviewer.py` — это сама кнопка Workflows
     (`a&&o.jsx(Ad,{tab:"workflows"…`), PDF цепляется за IFC, Design
     Code за PDF. Прятать Workflows раньше звена — сломать цепочку
     свежей установки. Патч `Ad` не зависит от кол-сайтов, но по смыслу
     (подписи у ВСЕХ вкладок, включая добавленные) — последним.
2. **Тексты** (подписи EN по запросу, пояснения RU):
   - generate: «Generate» / «Генерация изображений по описанию»
   - canvas: «Canvas» / «Холст — редактирование изображений, слои и маски»
   - upscaling: «Upscaling» / «Апскейл — увеличение разрешения изображений»
   - ifc: «IFC» / «IFC-вьювер — 3D-просмотр BIM-моделей»
   - pdf: «PDF» / «PDF-вьювер — просмотр документов PDF»
   - designcode: «Design Code» / «Вьювер сайт-базы дизайн-кода»
3. Идемпотентность: «уже пропатчено» определяется маркером `DBLT=`;
   бэкап `*.navbarlabels-bak` (только первый запуск).

## Не-цели

- i18n подписей/тултипов (жёстко зашиты; язык вкладок в рейке и так
  смешанный EN).
- Кнопка Workflows с плашкой «скоро» — просто скрыта.
- Мобильная/узкая раскладка — рейка одна, VerticalNavBar единственный
  в бандле.

## Риски

- `$e`/`E`/`W`/`re` — импорты модуля (проверено по import-хедеру),
  TDZ нет; рендер Ad выполняется после инициализации модуля.
- Ширина рейки вырастет на ширину самой длинной подписи («Design
  Code», «Upscaling» ~9px); проверить скриншотом, при обрезке —
  перенос строки (whiteSpace по умолчанию).
- Перезапуск более ранних setup-скриптов после этого патча безопасен:
  их «уже пропатчено»-детекты не завязаны на определение `Ad` и
  кнопку Workflows (проверено по коду setup_ifcviewer/pdfviewer/
  designcode).
