# Спека: журнал генераций в админ-панели — деньги, успех/ошибка, время

Дата: 2026-10-08. Ветка: `user`.

## Контекст

Админ-панель `/admin` (режимы users/sso) показывает пользователей студии:
почта, имя, роль, токен IR, количества файлов, последний вход. Владельцу
не видно, кто сколько денег потратил на генерацию и были ли ошибки —
приходится разбирать `ir_server.log` вручную.

Генерации идут через перехват `POST /api/v1/queue/{q}/enqueue_batch`
(`imagerouter_router.py`): канвас-генерация/правка/референсы и апскейлинг
(вкладка + quick-action). Пользователь известен из заголовка `x-studio-user`.
Ошибки любого рода (нет токена, модель не та, апстрим) всплывают тостом и
письмом в лог `[imagerouter] FAILED`, но не сохраняются структурированно.

Цены моделей есть в каталоге ImageRouter (`/v3/models`, кэш 10 мин):
`pricing.average`/`pricing.min` — доллары за картинку (`~$/img` в UI).

## Цели

1. В `/admin` у каждого пользователя видны: количество генераций
   (успешных/ошибок), оценка потраченных денег (`~$`), среднее время генерации.
2. Кнопка «Логи» у пользователя (и «журнал всех») — последние записи:
   время, тип (генерация/правка/апскейл), модель, статус (ок/ошибка),
   картинок, `~$`, длительность, текст ошибки.
3. Отдельно — статистика владельца (`admin-local`, генерации на глобальном
   ключе за деньги владельца).
4. Журнал переживает рестарт сервера (sqlite), ограничен по объёму.

## Не-цели (кандидаты на продолжение)

- VLM-текстовые вызовы (Ask AI, Prompt Enhancer, аналитик 3D) — у них
  тариф за токены, не за картинку; 3D уже показывает `usage` тостом.
- Облачные ноды Workflows (`devbim_cloud_nodes.py`) — тот же каталог цен,
  но другой путь исполнения; добавить позже тем же журналом.
- Точные суммы списаний (ImageRouter не отдаёт cost в ответе images API) —
  показываем оценку по каталогу, помеченную `~`.

## Решения

| Развилка | Решение | Почему |
|---|---|---|
| Хранилище | Таблица `gen_log` в `studio.sqlite` | Рядом с пользователями/владением, уже деплоится `setup_site_auth.py`, переживает рестарт |
| Точка записи | Мидлварь enqueue вокруг `asyncio.to_thread(handler)` | Видит и успех, и ВСЕ ошибки (включая «нет токена/модели» из тела хендлера), точное время, пользователь из scope |
| Стоимость | `pricing.average/min` каталога × картинок | Единственный доступный источник цены; оценка, помечаем `~`; нет в каталоге → пусто |
| Ошибки | Одна запись на попытку, `status=error`, текст до 500 символов | «Логи ошибка/успех» из запроса; полный стек — в ir_server.log |
| Объём | Кап 20000 строк, прун при записи | Безграничный журнал разрастётся |
| admin-local | Строка «Владелец» над таблицей, не в списке пользователей | Глобальный ключ = деньги владельца; мешать его в таблицу с кнопками пароля нельзя |
| Время генерации | Длительность хендлера (wall time) | Это и есть время генерации облака с сохранением |

## Схема

```sql
CREATE TABLE IF NOT EXISTS gen_log(
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  ts INTEGER NOT NULL,            -- unix
  user_id TEXT NOT NULL DEFAULT '',
  kind TEXT NOT NULL DEFAULT '',  -- txt2img|inpaint|outpaint|img2img|upscale
  model TEXT NOT NULL DEFAULT '',
  status TEXT NOT NULL DEFAULT 'ok',   -- ok|error
  images INTEGER NOT NULL DEFAULT 0,
  cost_usd REAL,                  -- NULL = цена неизвестна
  duration_s REAL NOT NULL DEFAULT 0,
  error TEXT
);
```

API (только admin, гейт панели `/admin`):

- `GET /admin/api/users` — к каждому пользователю добавляется `gen`
  `{total, ok, failed, images, cost_usd, avg_s, last_ts}`; в ответе
  `owner_gen` — та же статистика для `admin-local`.
- `GET /admin/api/genlog[?user=<uid>[&limit=N]]` — последние записи
  (новые сверху, лимит 1..1000, по умолчанию 200).

UI: колонки «Генерации ок/ош», «~$», кнопка «Логи» в строке; над таблицей
строка владельца и итог по всем; модалка журнала (тёмная тема панели).
