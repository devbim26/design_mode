# Дизайн: «Вырезать по контуру» (✂) на холсте InvokeAI

Дата: 09.09.2026, правки 10.09 по фидбеку пользователя. Запрос: «кнопка —
вырезать по контуру… ножницы рисуют замкнутую полилинию… подтвердить или
отменить… система вырезает кусок картинки и сохраняет его на новый слой
поверх текущего, чтобы потом этот кусочек я мог двигать по канвасу».
Правки 10.09: (1) подложка остаётся с ОРИГИНАЛОМ (дырки нет — кусок
копируется на новый слой); (2) слой-кусок НЕ выделяется (нет голубой
рамки-обводки; инструмент «Двигать» всё равно тащит кусок по хит-тесту);
(3) подтверждение — не только Enter, но и Ctrl+C; Ctrl+V вставляет копию
последнего вырезанного кусочка (ещё один новый слой, со сдвигом +24px);
(4) перетаскивание кусочков ПЛАВНОЕ — без привязки к сетке позиций
(остальные слои снапятся штатно; настройка snapToGrid не трогается);
(5) иконка ✂ — 1em, как у штатных иконок рейки; при активных ножницах
прочие кнопки-инструменты гаснут до неактивного вида (CSS через
body.devbim-cut-mode + .devbim-cut-rail), клик по другому инструменту
завершает режим.

## Состав

- **Кнопка ✂** — небольшая, в вертикальной рейке инструментов холста
  (вставляется в `div.chakra-button__group` рядом с «Кисть (B)»); рейка
  ищется по суффиксам хоткеев aria-label «(B)»+«(E)»+«(V)» — не зависит от
  локали. Стиль копируется с соседней кнопки.
- **Режим вырезания**: клики по канвасу ставят точки замкнутой полилинии
  (курсор crosshair). Клик рядом с первой точкой (≤14px экрана) замыкает
  контур. Enter/Ctrl+C/✓ — подтвердить, Esc/✕ — отменить. Пилюля с
  кнопками ✓/✕ и подсказкой — рядом с тумблером Mask/Layer (рядом выше).
- **Оверлей-превью** — SVG поверх `.konvajs-content` (fixed, pointer-events
  none, синхронизация rAF): рёбра, резиновая линия к курсору, полупрозрачная
  заливка, точки-вершины. Координаты экранные ↔ документа через
  `stage.getAbsoluteTransform().invert().point()`.
- Пока режим активен, pointerdown/dblclick/contextmenu над канвасом
  перехватываются в capture-фазе (konva не получает события); колесо НЕ
  перехватывается — зум живой.

## Логика (по «Подтвердить»/Enter/Ctrl+C)

1. Источник: выделенный растровый слой; если выделено не растровое —
   верхний растровый слой с объектами; нет такового → toast, отмена.
2. `adapter.renderer.getCanvas({rect})` — штатная растеризация Konva-группы
   слоя. rect = объединение границ документа, bbox полигона и clientRect
   группы, в координатах объектов (документ − position слоя).
3. Кусок = bbox-регион + заливка полигона `destination-in`. ИСХОДНИК НЕ
   МЕНЯЕТСЯ (destination-out убран 10.09) — подложка остаётся с оригиналом.
4. Кусок — `POST /api/v1/images/upload?image_category=other&
   is_intermediate=true&silent=true` (параметры в QUERY — грабля 6.2).
5. `stateApi.addRasterLayer({isSelected:false})` + опрос нового id →
   `canvas/entityRasterized` (replaceObjects:true, `isSelected:false` —
   БЕЗ рамки выделения) на новый слой поверх всех; position = bbox
   полигона. Выделение остаётся на прежнем слое.
6. «Буфер»: `{dto, position}` последнего куска; Ctrl+V (глобальный
   перехват в capture, только вне полей ввода и на вкладке canvas) —
   новый слой с копией, position = оригинал + 24×N.
7. Undo: [rasterLayerAdded]+[entityRasterized] на каждое действие —
   2 шага Ctrl+Z.
8. Плавный драг кусочков: `getPositionGridSize` (64px snap у приложения)
   оборачивается виджетом (раз на инстанс менеджера): пока тащат наш
   кусочек — 1px. Кусочки опознаются по префиксу id объекта
   `image_devbimcut_` (живёт в состоянии, переживает F5); детект драга —
   `adapter.transformer.konva.proxyRect.isDragging()`.

## Файлы

- `imagerouter/devbim_cut_tool.js` — виджет (ES5, без зависимостей).
  Мост `window.__devbimCanvasBridge.getManager()`.
- `setup_imagerouter.py`: `deploy_cut_tool()` — копия в
  `dist/devbim-cut-tool.js` + `<script defer>` в index.html (бэкап
  `index.html.cuttool-bak`, идемпотентно), вызов из main().
- `tests/test_cut_tool.py` — статические проверки (деплой, тег, node
  --check, маркеры; исходник не стирается, isSelected:false, Ctrl+C/V).
- E2E (Playwright, живой сервер): контур → Ctrl+C → подложка цела
  (попиксельно), кусок на новом слое без выделения, Ctrl+V ×2 → копии со
  сдвигом, «Двигать» тащит кусок по хит-тесту, undo.

## Поведение-края

- Канвас-панель демонтирована (dockview) → кнопка скрыта, активный режим
  отменяется.
- <3 точек — ✓/Ctrl+C заблокированы (toast). Ошибка upload → toast,
  ничего не меняется.
- Ctrl+V перехватывается ТОЛЬКО когда есть свой «буфер» и пользователь не
  в поле ввода; иначе событие уходит приложению/ОС штатно.
- Отладка: `window.__devbimCut` (state, cancel, confirm, paste, clipboard).
